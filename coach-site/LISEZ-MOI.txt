MON COACH NUTRITION : installation sur ton iPhone

1. Crée un compte gratuit sur github.com, puis un dépôt public (par exemple « coach »).
2. Glisse les 5 fichiers de ce dossier dans le dépôt (Add file > Upload files) et valide.
3. Dans le dépôt : Settings > Pages > Source : « Deploy from a branch », branche « main », dossier « / (root) » > Save.
4. Après une minute, ton site est sur https://TON-PSEUDO.github.io/coach/
5. Ouvre ce lien dans SAFARI sur l'iPhone, appuie sur Partager > « Sur l'écran d'accueil ».

Une fois installé de cette façon, le scan de code-barres et la recherche Open Food Facts fonctionnent.
Raccourci Apple Santé : dans l'app, onglet Moi > Santé > « Synchroniser avec un Raccourci ».
Sauvegarde : Moi > Profil > « Copier ma sauvegarde ».
